# Anamaría Espinoza: Learning Transformation Portfolio

Source and GitHub Pages build for Anamaría's professional portfolio.

Live GitHub Pages URL: https://anamariae.github.io/portfolio/

- `app/` contains the shared portfolio source.
- `github-pages-src/` contains the static entry point.
- `docs/` contains the generated GitHub Pages build.
- Run `npm run build:pages` after portfolio changes.

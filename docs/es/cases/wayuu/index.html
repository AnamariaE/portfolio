EL PROYECTO

El formato se adapta a la comunidad, y no al contrario.

Los Círculos de Aprendizaje Wayuu y su narrativa forman parte de WikiLearn, dentro de mi trabajo con Wikimedia. El proyecto comenzó con investigación cultural y colaboración directa antes de diseñar cualquier recurso de aprendizaje.

Formatos culturalmente relevantes

Enfoque
Comprender cómo se crea, comparte y vive el conocimiento en la comunidad, y utilizar esa lógica para dar forma a la experiencia digital.
Entregables
Video narrativo, guía visual, infografías con poco texto, componentes HTML interactivos y un recorrido de aprendizaje para facilitadores.
Principio
La accesibilidad no es una concesión ni una lista de control final. Es el estándar que hace que el trabajo sea más claro para todas las personas.
